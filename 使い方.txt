==========================================
 SALON BOARD 自動投稿ツール　使い方
==========================================

写真を入れておくと、AI（ChatGPT。OpenAI の有料API）が文章を作り、
SALON BOARD にスタイルとブログを自動で投稿します
（クーポン選び・反映申請も自動）。
メンズとレディースは別々のツールが投稿します（ログインが別のため）。
AIのモデル（用途ごと。かっこ内は考える強さ）：
 画像の解析 gpt-6.1-sol（中）／文章づくり gpt-6-luna（中）／
 最後の確認 gpt-6.1-sol（中）／
 トレンドのWeb検索 gpt-6-astra（高。毎週日曜）

ツールのフォルダ： C:\自動投稿サロンボード
  起動.bat      ← これ1つで、メンズとレディースの両方が起動
  使い方.txt    ← このファイル
  images        ← 写真を入れる所（→ 2.）
  設定          ← 時間・休み・件数・クーポンなど（→ 6.）
  トレンド語    ← トレンド語の Excel（→ 6.）
  app\mens      ← メンズのツール（プログラム。ふだんは開きません）
  app\ladies    ← レディースのツール（同じく）

==== 1. 毎日やること ======================
 1) 写真を入れます（→ 2.）。
 2) 朝10:00までに、Chrome で SALON BOARD に自分でログインします
    （ツールはパスワードを入れません）。
    ・メンズ：いつもの Chrome で、メンズのログイン
    ・レディース：レディース用の Chrome で、レディースのログイン
    拡張機能は Chrome ごとに1つです。いつもの Chrome には
    「サロン投稿アシスタント（メンズ）」、レディース用の Chrome には
    「サロン投稿アシスタント（レディース）」が入っています。
 3) ツールのフォルダの「起動.bat」（「起動」とだけ出ることも
    あります）をダブルクリックします。黒い画面が2つ開きます
    （題名に mens / ladies と出ます）。メンズとレディースの
    Chrome も自動で開きます（開かないときは自分で開きます。
    ログインがまだなら、ここでします）。
 4) 黒い画面2つと Chrome は開いたままにします（最小化は可）。
    投稿中に別の Chrome 画面が開いても触りません（自動で閉じます）。
 つけたままの日は、1) の写真を足すだけです。
 止めるとき：黒い画面の右上の「×」で、2つとも閉じます。
   投稿の途中でも大丈夫です（二重には投稿しません）。
 ・接続コードが出たとき：それぞれの黒い画面に出たコードを、
   そのツールの Chrome の拡張機能に入力します
   （mens の画面のコード → いつもの Chrome、
     ladies の画面のコード → レディース用の Chrome）。
 ・夜もつけたままで大丈夫です（自動でスリープしません。画面が消えるのは可）。
 ・スリープ・ふたを閉じる・電源オフ・ネット切断の間は、投稿できません。
 ・「すでに別のウィンドウで動いています」→ 新しい画面を閉じます。

==== 2. 写真の入れ方 ======================
 ツールのフォルダの images\pending の中の、次の4つに入れます。
   メンズのスタイル：      images\pending\style\mens
   メンズのブログ：        images\pending\blog\mens
   レディースのスタイル：  images\pending\style\ladies
   レディースのブログ：    images\pending\blog\ladies
 ・使える写真：JPEG・PNG・WebP（iPhone 標準の HEIC は不可）。
   1枚25MBまで。ふつうのスマホ写真なら問題ありません。
 ・スタイルとブログには、別々の写真を入れます。
 ・同じ写真は取り込まれません（使用済み、またはもう一方のフォルダに
   入れたもの）。フォルダに残り、黒い画面に「同じ画像がすでに
   登録されている」と出ます。別の写真に替えてください。
 ・写真と補足ファイル（下で説明）以外（メモなど）は入れません。
 ・お客様の写真は、必ず同意を得てください（写真は解析のため
   AI（OpenAI）に送られます）。
 ・入れた写真は10秒ほどでフォルダから消えます（取り込んだ印で、
   異常ではありません）。投稿後は app\mens\images\posted
   （レディースは app\ladies\images\posted）、失敗したら
   同じ所の failed フォルダに入ります。
 ・元の写真を残したいときは、コピーを入れてください。

 【補足ファイル】パーマなど写真で分からない施術を伝えるとき（なくても可）
 1) 写真より先に作ります（写真のあとに作ったものは使われません）。
 2) メモ帳に次の1行を書き写し（記号と英字は半角）、twist_spiral の
    所を下の「選べる名前」のどれかにします。
      {"category_hint": "twist_spiral"}
 3) 「名前を付けて保存」で、ファイルの種類「すべてのファイル」、
    文字コード「UTF-8」にし、写真と同じ名前＋.json で、
    写真を入れるフォルダに保存します（例：IMG_0001.json）。
 4) そのあと写真（例：IMG_0001.jpg）を入れます。
 メンズで選べる名前：twist_spiral（ツイストスパイラル）、
   mens_perm（メンズパーマ）、twist（ツイスト）、mash（マッシュ）
 twist_spiral・mens_perm・twist はパーマ用のクーポンが自動で選ばれます
 （mash は通常のメンズカットのクーポンのままです）。

==== 3. 投稿の時間と件数 ==================
 ・10:00〜21:00 に、スタイルとブログを等間隔に交互に投稿します。
   件数はメンズ・レディースで別々です（→ 6. 件数とクーポン）。
 ・ツールが止まっていた間（閉じていた・一時停止・スリープ・
   ログアウト）の分は、あとから投稿しません。その日の件数が減ります。
   10:00 までに起動しておくか、つけたままにしましょう。
 ・写真が足りないときは、ある分だけ投稿します。

==== 4. 状態を見る・一時停止・やり直し ====
 命令は、メンズは app\mens、レディースは app\ladies のフォルダで
 入力します（それぞれのツールのことだけが分かります）。
 PowerShell の開き方：エクスプローラーで app\mens（または
 app\ladies）のフォルダを開き、画面上部のアドレス欄（フォルダの
 場所が出ている所）をクリックして、powershell と入力して Enter。
 出てきた画面が PowerShell です。
 ・入力するのは PowerShell の画面です（起動.bat の黒い画面ではありません）。
 ・命令は必ず npm.cmd で始めます（npm だけでは動きません）。

 【状態を見る】（見るだけで、何も変えません）
     npm.cmd run status
   次の3つが出ていれば正常です。
   ・一時停止: なし
   ・配布の状態: 投稿できます（ほかの表示のときは、続く理由を読みます）
   ・Chrome拡張: 接続中
   そのほか：モード 本番（live）＝実際に投稿中、次回の枠＝次の投稿時刻、
   成功＝今日投稿できた件数、投稿待ち＝待っている写真の数（スタイルと
   ブログの合計）、件数とクーポン＝いま使っている件数とクーポン。
   「このツールでは扱いません」は、もう一方のツールの分です（正常）。

 【一時停止する／再開する】（ツールは開いたまま、投稿だけ止めます）
     npm.cmd run pause
     npm.cmd run resume

 【失敗した投稿をやり直す】通信などの一時的な失敗なら、これだけです。
     npm.cmd run retry
   写真や設定が原因のときは、直してから（→ 5.）、status に出る例を
   そのまま入力します（abc123 の所が、その投稿の番号です）。
     npm.cmd run retry -- --id abc123
   status に「ツールを止めてから」と出ていたら、そのツールの黒い画面を
   「×」で閉じてから入力し、終わったら 起動.bat をもう一度開きます。

==== 5. 困ったとき ========================
 まず PowerShell（開き方は 4.）で  npm.cmd run status  を実行します。
 ■ 何もしなくてよい表示（黒い画面や status に出ます）
 ・AIが混み合っている（503 など）→ 自動でやり直します。
 ・AIの利用額の予算か1日の利用回数の上限に達した → 翌日の0時
   （1か月の予算なら翌月）に自動で再開します。
 ・本日の予定なし → 10:00〜21:00 の外です。
 ・ツールが予期せず終了しました → 10秒後に自動で起動し直します。
   「自動での起動し直しをやめました」→ 開発担当（このツールを作った人）へ。
 ・結果不明 → 2分・5分・15分後に自動で確かめます。
 ・SALON BOARD で投稿者が設定したスタイリスト名、スタイル一覧に「要確認」
   （全部のスタイルに出ます）→ どちらも正常です。

 ■ 自分ですること
 ・「この Chrome は「（店舗名）」でログインしています。この拡張機能は
   （メンズ）用です…」（拡張機能のポップアップ・status に出ます）
   → 拡張機能を違う Chrome に入れています。投稿はしません。
   （メンズ）はメンズでログインする Chrome に、（レディース）は
   レディース用の Chrome に入れ直します（分からなければ開発担当へ）。
   その Chrome で別の店舗にログインしていただけなら、正しい店舗で
   ログインし直せば、30秒ほどで消えます。
 ・「（メンズ）の拡張機能が入った Chrome が見つかりません」
   （黒い画面）→ ツールは動いています。Chrome はご自分で開き、
   上と同じように拡張機能を入れ直します。
 ・SALON BOARD のログインが切れた（status に理由が出ます）
   → そのツールの Chrome でログインし直し、PowerShell に次を入力します。
       npm.cmd run resume
 ・結果不明のまま残った → 二重投稿を防ぐため、自動では送り直しません。
   SALON BOARD の投稿一覧を見て、結果を入力します（abc123 は番号）。
   載っていた：
     npm.cmd run reconcile -- --id abc123 --registered --basis "一覧で確認"
   載っていない：
     npm.cmd run reconcile -- --id abc123 --not-registered --basis "一覧になし"
   載っていなかった投稿は、そのあと retry -- --id でやり直せます。
 ・AI_AUTH_ERROR（AIの認証エラー）→ 開発担当へ連絡します。
 ・写真が使えない → app\mens\images\failed（レディースは
   app\ladies\images\failed）の中に、その投稿の番号のフォルダが
   あります。中の failure.json をメモ帳で開くと理由が読めます。
   JPEG か PNG で保存し直して入れるか、別の写真にします。
 ・設定ファイルに問題があります → 表示されたファイルの項目を直すか、
   変える前に戻し、起動.bat をもう一度ダブルクリックします。
 ・AIのエラーが続く → ツールを止め、次の画面を開発担当へ送ります。
       npm.cmd run ai:test

 ■ 直らないとき：status の画面、いつ何が起きたか、その日の記録（ログ）
   を開発担当へ送ります。ログはメンズが app\mens\logs、レディースが
   app\ladies\logs の日付のファイルです（例：app-2026-10-08.jsonl。
   キーは入っていません）。

==== 6. 設定を変えたいとき ================
 ツールのフォルダの「設定」フォルダのファイルを、メモ帳で開いて
 書き換えます。保存すると30秒ほどで反映されます。
 くわしくは 設定 フォルダの README.md（メモ帳で開きます）。

 【1日の件数・クーポン】メンズは 件数とクーポン（メンズ）.txt、
   レディースは 件数とクーポン（レディース）.txt。1行に1つです。
     スタイルの件数: 10
     ブログの件数: 10
     いつものクーポン: メンズカット¥6000
     クーポン・twist_spiral: メンズカット+スパイラルパーマ￥13000
   ・数字やクーポンの名前だけを変えます。「: 」の左側は変えません。
   ・クーポンの名前は SALON BOARD に出ているとおり（1字も変えずに）。
     「なし」と書くと、そのクーポンは選びません。
   ・件数を変えると、毎日必要な写真の枚数も変わります。
   ・書き間違いがあると、直すまでこのファイルは使わず、前の件数・
     クーポンで動きます（status に理由が出ます）。

 【時間・休み・検索ワード】作業指示書.md（メンズ・レディース共通）
   ・今ある行を書き換えます（同じ行を足さないでください）。
   ・休みの日は「## 営業時間」の下に1行足します。
       臨時休業: 2026-12-31
   ・期間限定の変更（例：お盆だけ営業時間を変える）は README.md へ。
   ・検索ワード（文章で重点的に使ってほしい語）は、いちばん下に
     次の3行をそのまま書き写します。
       ## 検索ワード
       操作: 追加
       - 似合わせカット
     見出しは1回だけ。語を増やすときは「- 語」の行を足します。
     1行に1語、30文字まで。施術名・料金・割引は使えません。
     使ってほしくない語は「## 除外検索ワード」の下に「- 語」。

 【文章方針】作業指示書.md の「## 文章方針」はメンズ・レディース共通です。
   分けたいときは、README.md の例のとおり、対象カテゴリー: メンズ
   （または レディース）と書いたファイルを 設定 フォルダに足します。

 【トレンド語】流行の言葉を毎週日曜の朝6時以降に自動で調べます。
   ・結果：トレンド語フォルダの トレンド語一覧（メンズ）.xlsx と
     トレンド語一覧（レディース）.xlsx（見るだけ）
   ・自分で足す：同じフォルダの 手動のトレンド語.xlsx のシート
     メンズ か レディース の A列（左端）に、1行に1語。
     保存して閉じると、1分ほどで使われます。

 【変えないもの】設定 フォルダの 投稿先URL設定.md は変えません。

==== 7. 注意 ==============================
 ・同じ内容を SALON BOARD に手で投稿しないでください。
 ・images の中は、写真を足す以外（移動・名前変更・削除）しません。
 ・app\mens と app\ladies の中の data・logs・ledger・images の
   フォルダ（ツールの記録置き場）は、消したり、書き換えたり、
   古いコピーで置き換えたりしません。
 ・ツールのフォルダの .env は開いたり人に渡したりしません。
 ・ツールのフォルダを移すときは、ツールを2つとも止めてからにします。
 ・Mac に移すときは、2つとも止めてから「Mac用に書き出す.bat」をダブルクリックします。
 ・Chrome の拡張機能（右上のパズルの形のアイコン）にある
   「サロン投稿アシスタント（メンズ）」（いつもの Chrome）と
   「サロン投稿アシスタント（レディース）」（レディース用の Chrome）は
   消しません。
 ・app\mens・app\ladies の README.md は開発担当用です。
