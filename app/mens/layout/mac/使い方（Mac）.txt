==========================================
 SALON BOARD 自動投稿ツール　使い方（Mac 版）
==========================================

写真を入れておくと、AI が文章を作り、SALON BOARD にスタイルと
ブログを自動で投稿します。メンズとレディースは別々のツールが
投稿します（ログインが別のため）。

ツールのフォルダ： ホーム > SalonBoard（おすすめの置き場所）
  起動.command  ← これ1つで、メンズとレディースの両方が起動
  使い方.txt    ← このファイル
  images        ← 写真を入れる所（→ 4.）
  設定          ← 時間・休み・件数・クーポンなど（→ 6.）
  トレンド語    ← トレンド語の Excel（→ 6.）
  bin           ← salonboard コマンド（→ 5.）
  app/mens      ← メンズのツール（プログラム。ふだんは開きません）
  app/ladies    ← レディースのツール（同じく）

==== 0. 大事な注意 ========================
 ・Windows のツールと Mac のツールを、同時に動かさないでください
   （二重に投稿されます）。Windows 側は書き出したときに一時停止
   してあります。Mac で動かし始めたら、Windows 側は起動しません。
 ・フォルダは「書類」や「デスクトップ」ではなく、ホームの中に
   置きます（iCloud の同期で動かなくなることがあるため）。

==== 1. 置き場所 ==========================
 1) Windows から受け取った SalonBoard-Mac-….zip（USB メモリで
    移すのがおすすめです）を、Finder で
    ホーム（家のマークのフォルダ）に置きます。
 2) ダブルクリックして展開します。「SalonBoard」フォルダが
    できれば完了です（ホーム > SalonBoard）。
 ・ほかの場所に置いても動きますが、置いた後に移したときは、
   もう一度 起動.command を開きます。

==== 2. はじめて起動するとき ==============
 先に Google Chrome を入れておきます（入っていないときは、
 起動.command が Chrome のページを開きます）。インターネットにつないでおきます。
 1) SalonBoard フォルダの「起動.command」を、右クリック（または
    control キーを押しながらクリック）して「開く」を選びます。
    「開発元を確認できません」と出たら、もう一度「開く」を押します。
    「開く」が無く「完了」しか押せないとき（macOS 15 以降）は、
    「完了」を押してから、アップルメニュー > システム設定 >
    プライバシーとセキュリティ を開き、下のほうの「起動.command」の
    「このまま開く」を押して、Mac のログインパスワードを入れます。
    それでも開けないときは、ターミナル（アプリケーション >
    ユーティリティ）で  bash ~/SalonBoard/起動.command  と打ちます。
    （この操作は最初の1回だけです。次からはダブルクリックで開きます）
 2) ターミナル（文字だけの画面）が開き、必要なもの（Node.js と
    部品）を自動で入れます。初回は10分ほどかかることがあります。
    パスワードは聞かれません。
 3) 終わると、メンズとレディースのウィンドウが1つずつ開きます。
    このウィンドウは閉じないでください（最小化は可）。

==== 3. Chrome の準備（はじめての Mac だけ）==
 1) Chrome の右上の人のアイコン →「追加」で、ユーザーを2つ
    作ります（例：「メンズ」と「レディース」）。
 2) それぞれの Chrome で SALON BOARD にログインします。
    ・メンズ の Chrome：メンズのログイン
    ・レディース の Chrome：レディースのログイン
 3) それぞれの Chrome で、アドレス欄に chrome://extensions と
    入力し、右上の「デベロッパー モード」をオンにします。
    「パッケージ化されていない拡張機能を読み込む」を押して、
    次のフォルダを選びます。
    ・メンズ の Chrome：SalonBoard > app > mens > apps > extension > dist
    ・レディース の Chrome：SalonBoard > app > ladies > apps > extension > dist
 4) 接続：メンズのウィンドウに出た「拡張機能の接続コード」を、
    メンズの Chrome の拡張機能（右上のパズルの形のアイコン）の
    ポップアップで「接続」を押して入力します。レディースも同じです。

==== 4. 毎日やること ======================
 1) 写真を入れます。SalonBoard > images > pending の中の4つです。
      メンズのスタイル：      images/pending/style/mens
      メンズのブログ：        images/pending/blog/mens
      レディースのスタイル：  images/pending/style/ladies
      レディースのブログ：    images/pending/blog/ladies
    使える写真：JPEG・PNG・WebP（iPhone の HEIC は不可。
    iPhone の「設定 > カメラ > フォーマット」で「互換性優先」にすると JPEG になります）。
 2) 朝10:00までに、それぞれの Chrome で SALON BOARD にログインします。
 3) 起動.command をダブルクリックします（つけたままの日は不要）。
    ターミナルで  salonboard start  と打っても同じです。
 止めるとき：メンズとレディースのウィンドウを、2つとも閉じます
 （または、そのウィンドウで control キーを押しながら C）。

 ・スリープの注意：ツールが動いている間、Mac は自動ではスリープ
   しません（画面が消えるのは大丈夫）。ただし、ノートの Mac は
   ふたを閉じるとスリープして投稿できません。ふたは開けたままに
   します（外部ディスプレイにつないだ使い方は除きます）。
 ・電源アダプタにつないでおきます。

==== 5. 状態を見る・一時停止・やり直し ====
 ターミナル（Launchpad で「ターミナル」）を開いて入力します。
 どのフォルダにいても使えます。
     salonboard status                 状態を見る（両方）
     salonboard mens pause             メンズの投稿を一時停止
     salonboard mens resume            メンズの一時停止を解除
     salonboard ladies retry           レディースの失敗した投稿をやり直す
     salonboard help                   使い方
 ・画面に「npm run ○○ -- --id abc123」のように出たときは、
   salonboard mens ○○ --id abc123 のように書き換えて入力します
   （レディースなら mens を ladies に）。
 ・「salonboard が見つかりません」と出たら、ターミナルを一度閉じて
   開き直します。それでもだめなら、起動.command をもう一度開きます。

==== 6. 設定・トレンド語 ==================
 ・設定フォルダのファイルを「テキストエディット」で開いて書き換えます。
   保存すると30秒ほどで反映されます。件数とクーポンは
   件数とクーポン（メンズ）.txt・件数とクーポン（レディース）.txt。
   書き方は Windows のときと同じです（設定 > README.md）。
 ・テンプレートの Excel も設定フォルダに入っています。
 ・トレンド語フォルダの 手動のトレンド語.xlsx に、自分で語を足せます。

==== 7. 困ったとき ========================
 ・起動.command が開けない → 右クリック >「開く」で開きます。
   macOS 15 以降は システム設定 > プライバシーとセキュリティ の
  「このまま開く」を使います（→ 2. の 1)）。
 ・「インターネットにつながっているか確かめて」→ Wi-Fi を確かめて、
   もう一度 起動.command を開きます。
 ・「Google Chrome が入っていません」→ Chrome を入れて、もう一度開きます。
 ・「すでに動いています」→ 新しいウィンドウは閉じてかまいません。
 ・拡張機能が入った Chrome が見つからない → 3. の 3) をやり直します。
 ・直らないとき：ウィンドウの画面と、SalonBoard > .runtime > setup.log、
   app > mens（または ladies）> logs の日付のファイルを開発担当に送ります。
   （.runtime は隠しフォルダです。Finder で command + shift + . を押すと見えます）

==== 8. 注意 ==============================
 ・images の中は、写真を足す以外（移動・名前変更・削除）しません。
 ・app/mens と app/ladies の中の data・logs・ledger・images の
   フォルダは、消したり書き換えたりしません。
 ・SalonBoard フォルダの .env（隠しファイル）は開いたり人に渡したりしません。
 ・Windows に戻すときは開発担当に相談してください。
